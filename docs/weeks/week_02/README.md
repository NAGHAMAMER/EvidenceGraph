# الأسبوع الثاني — البحث العلمي متعدد المصادر

## هدف الأسبوع

إنشاء طبقة بحث علمي تجمع أوراقًا من عدة مصادر، وتحول نتائجها المختلفة إلى صيغة موحدة يمكن استخدامها لاحقًا في NLP والـAgent وبناء Evidence Graph.

## حدود الأسبوع

يتضمن هذا الأسبوع:

- إنشاء صيغة موحدة للأوراق العلمية.
- ربط OpenAlex.
- ربط Crossref.
- البحث في المصدرين بالتوازي.
- حذف الأوراق المتكررة.
- دمج معلومات الورقة الموجودة في أكثر من مصدر.
- إنشاء API للبحث.
- إنشاء اختبارات وحدات واختبارات API.

لا يتضمن هذا الأسبوع بعد:

- Embeddings.
- البحث الدلالي.
- استخراج الادعاءات والأدلة.
- تصنيف الأدلة كمؤيدة أو معارضة.
- Agent لاتخاذ قرارات البحث.
- قاعدة البيانات.
- واجهة المستخدم.

تبدأ مكونات NLP الفعلية في الأسبوع الثالث.
